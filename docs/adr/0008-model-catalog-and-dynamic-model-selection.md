# Model Catalog 支撑 /model 全局动态选择

susan 的 provider entry 可以静态声明 Model Catalog，而不是在打开模型选择器时发现上游模型。这保证 `/model` 可以离线渲染、对 OpenAI-compatible baseURL 确定可用。模型的 context window 与最大输出 tokens 默认值在代码中定义，需要定制时由具体模型条目覆盖。省略 `models` 的 provider 在 `/model` 中显示空目录，不把根节点 `defaultModel` 合成为目录项；空目录 provider 一律不可被应用，即使根节点 `defaultModel` 显式存在也不能激活它。Reasoning Effort 不写入模型配置，而由 Provider Type 的代码常量提供集合与顺序；Config 可省略默认档位，但没有隐式 fallback，需要用户重新选择 model 并显式设置。TUI 启动时只提示模型配置未完整，不强制打开选择器。Anthropic 的 extended thinking token budget 不映射到 Reasoning Effort。

`/model` 选择器中，上下键选择模型，Tab 按 Config JSON 中的 provider 声明顺序循环切换，左右键调整 Reasoning Effort，Enter 一次性应用，Esc 取消。Provider entry 不维护各自的默认模型；Tab 到非默认 provider 时选中其 Model Catalog 的第一个模型，根节点 `defaultModel` 只作为默认 provider 的当前模型。选择结果是全局 Active Model Configuration，并通过“先原子写入 Config、成功后再更新 Harness”的事务顺序回写默认 provider、默认模型与默认 Reasoning Effort，而不是只改变当前 Session；Agent Loop 空闲或 Pending 时允许切换，切换后的下一次显式 retry 使用新配置。未注册 adapter 的 Provider Type 仍 fail-fast，不能因为 UI 具备 provider 切换能力而绕过运行时契约。

Active Model Configuration 完整时才允许发起请求；提交或重试时若 provider、model 或 Reasoning Effort 缺失，则打开 `/model` 选择器。选择器初始的 model 为当前 `defaultModel`（若存在于目录），`defaultModel` 省略时显示未设置，需要用户手动选择模型；Reasoning Effort 显示未设置，左右键第一次按下后才显式选中该 Provider Type 常量的第一档，未设置时 Enter 不可用。`defaultProvider`、`defaultModel` 与 `defaultReasoningEffort` 均只允许字段省略，`null` 和空字符串是 schema error；显式填写时分别必须指向已配置 provider、属于默认 provider 的 Model Catalog，以及属于默认 provider 的 Reasoning Effort 常量集合。`defaultProvider` 省略时，`defaultModel` 与 `defaultReasoningEffort` 可以成对出现或同时省略；成对出现时它们只是 picker 的偏好值，匹配某个 provider 的模型与 Provider Type 支持档位时预选，不匹配时显示未设置，成功应用后回写明确的 `defaultProvider`、`defaultModel` 与 `defaultReasoningEffort`。

回写前会重新读取当前 Config 路径并基于最新内容合并，只覆盖默认模型选择相关字段，不覆盖其他字段。Harness 通过 `configure-model` 命令原子替换 provider client、model、Reasoning Effort、context window 与最大输出 tokens；Session Transcript 和 Pending Agent Loop 保留。Session 会记录每次请求实际使用的 model 与 Reasoning Effort 用于审计，但恢复 Session 时仍使用当前全局默认配置，不用历史配置覆盖。

若 provider 显式声明 `models`，列表必须非空且 `id` 唯一；根节点 `defaultModel` 可省略，显式填写时必须属于默认 provider 的列表。若 `models` 省略，该 provider 不可被应用，根节点 `defaultModel` 也不能激活它。Provider alias 禁止纯数字字符串，避免 JavaScript object 对 integer-like key 重排导致 JSON 声明顺序不可靠。`providers` 为空时允许 TUI 启动并提示模型配置未完整；提交或重试打开 `/model` 后显示没有可用 provider，用户只能修改 config 后重新加载或退出。
