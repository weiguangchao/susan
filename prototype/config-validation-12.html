susan · Config loader THROWAWAY PROTOTYPE

Config 缺失与错误提示流程

这个原型不编辑、不创建、不修复 Config。它只模拟读取、补默认值、校验、提示，以及用户手动修改后的重新读取。

要验证的决定：用户完全拥有 Config；susan 只把缺省 optional 字段解析为默认值。文件不存在、空文件、schema / permission / provider 错误均由 TUI 解释，等待用户手动修复。
